## :battery: Propósitos
- Desarrollar interfaces de usuario eficientes, accesibles y atractivas que conecten al usuario con la lógica y funcionalidades de una aplicación, asegurando una <strong>experiencia fluida, intuitiva y compatible</strong> en diferentes dispositivos y navegadores.
- Traducir diseños (mockups) en código funcional con HTML, CSS y JavaScript.
- Asegurar que el sitio sea <strong>responsivo</strong> (se vea bien en todos los tamaños de pantalla).
- Optimizar el rendimiento del sitio web en el navegador.
- Integrar el Front-End con servicios y datos del Back-End (APIs).
- Mejorar la accesibilidad y usabilidad de la aplicación.
- Colaborar con diseñadores UX/UI y desarrolladores Back-End.
